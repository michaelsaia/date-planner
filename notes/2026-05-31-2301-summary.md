## Design Decisions
- **SVG favicon over ICO:** SVG scales to any size, is smaller in bytes, and is editable. Supported by all modern browsers. The old default Next.js favicon.ico was removed.
- **`next/og` ImageResponse for apple-icon and OG image:** Dynamic generation avoids committing binary PNG files. These are generated at build time and cached.
- **Layout files for client page metadata:** Next.js requires metadata exports from server components. Since login, signup, onboarding, and profile pages use `"use client"`, metadata is exported from thin layout wrapper files instead.
- **Template title pattern:** `"%s | Date Planner"` keeps page titles DRY — each page only specifies its unique part.
