## Decisions Made
- **Vitest over Jest** — faster, native ESM, better Vite/Next.js integration
- **Zod v4** — installed as latest; API is backward-compatible with v3 patterns
- **Preview server** — used plain Node.js HTTP server instead of Next.js dev since the container cannot sustain Turbopack or webpack dev processes
- **Warm color palette** — rose/amber theme for a date planning app (primary: #e11d48)
