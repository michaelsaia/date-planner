## Design Decisions
- **Touched-on-blur pattern:** Errors appear after the user interacts with a field, not on initial render. This avoids showing errors before the user has had a chance to type.
- **Submit-reveals-all:** Clicking submit marks all fields as touched, ensuring users see all validation issues at once.
- **No browser native validation:** Removed `required` and `minLength` HTML attributes to provide consistent custom validation UX instead of browser-native popups.
- **Next button not disabled:** Changed from disabled-when-invalid to always-clickable with validation feedback on click. Better UX — users understand why they can't proceed.
